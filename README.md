# Charvet Électronique — maquette de refonte

Maquette multipage (accueil, produits, marques, histoire, contact) avec assistant guidé, panier de demande de devis et animations.
Site statique : ouvrir `index.html` ou activer GitHub Pages sur la branche `main` (dossier racine).

Version de présentation, volontairement non indexée par les moteurs de recherche (`noindex` + `robots.txt`).
Les éléments entre crochets (téléphone, témoignages, logos clients…) sont à remplacer par les contenus réels.
